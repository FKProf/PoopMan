# Contributing

Thanks for your interest in contributing to PoopMan.

## Before you start

- Read the [Code of Conduct](./CODE_OF_CONDUCT.md).
- Check existing issues and pull requests before opening a new one.
- For substantial changes, open an issue first to discuss the proposal.

## Development setup

1. Install Visual Studio 2022 with .NET 9 support.
2. Restore NuGet packages for `PoopMan.sln`.
3. Set `PoopMan` as the startup project.
4. Build and run the game locally.

## Project structure

- `PoopMan/` contains the game executable and content pipeline assets.
- `PoopManLibrary/` contains shared gameplay and engine code.

## Pull request process

1. Keep changes focused and scoped to a single task.
2. Update documentation when behavior or contributor-facing workflow changes.
3. Run the relevant build and tests before submitting.
4. Describe the change clearly and link related issues.
5. Be responsive to review feedback.

## Reporting bugs

When reporting a bug, include:

- What happened
- What you expected to happen
- Steps to reproduce the issue
- Your environment details when relevant

## Suggesting enhancements

When suggesting an enhancement, explain:

- The problem you are trying to solve
- The proposed behavior or improvement
- Any alternatives you considered
