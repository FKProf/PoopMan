# Security Policy

## Supported Versions

Security fixes are applied to the latest code on the default branch.

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Instead, report vulnerabilities privately through GitHub's security reporting
features for this repository. If private reporting is not available, contact the
maintainers through GitHub and include:

- A description of the issue
- Steps to reproduce it
- Potential impact
- Any suggested remediation

You can expect an initial acknowledgement within 7 days. We will investigate,
confirm the issue, and coordinate a fix and disclosure timeline as appropriate.
